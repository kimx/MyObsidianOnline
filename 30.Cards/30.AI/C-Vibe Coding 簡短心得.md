# Foreword
- 這陣子試用Vibe Coding寫一個小型的進銷存系統，並吸收網路大師們的感言，整理如下。
# 心法
- 雛型、小工具、用完即丟的，提示詞以目的性、大功能為主。
- 若是正式產品
	- 產生的程式一定要看得懂，否則會變Panic Coding。
	- 提示詞要循序漸進，第一次為主要目的、技術架構，之後以每個小功能。
# 技術
- 我以目前個人熟悉的.NET為後端+Vide Coding 支援較完整的React為主。
- 要以API為導向，前端由Vibe Coding 自適應，將OpenAPI Json丟給它，幾乎完美的產出。
